처음 만드는 홈페이지 — Claude와 함께 하는 입문 가이드

코드를 몰라도 VS Code와 Claude를 쓰면 간단한 소개용 홈페이지를 직접 만들고 인터넷에 올릴 수 있어요. 코드는 Claude가 쓰고, 여러분은 원하는 걸 말로 설명하고 화면으로 확인하는 역할을 맡습니다.

전체 흐름은 이렇게 5단계예요.

  1. 프로그램 3개 설치하기
  2. 첫 프롬프트로 홈페이지 뼈대 만들기
  3. 내 컴퓨터에서 화면 확인하기
  4. 조금씩 고쳐가며 완성하기 (중간중간 저장)
  5. 인터넷에 올려서 주소 받기

목차

섹션 담긴 내용
1. 준비물 설치하기 VS Code, Node.js, Claude 확장 설치와 작업 폴더 준비
2. 첫 프롬프트로 뼈대 만들기 복사해서 쓰는 첫 프롬프트, Claude 권한 요청 허용·거절 기준
3. 내 컴퓨터에서 화면 확인하기 npm run dev로 실행하고 브라우저에서 보는 법

막혔을 때 자주 겪는 증상과 먼저 해볼 것

1. 준비물 설치하기

설치할 건 3개뿐이고, 처음 한 번만 하면 돼요.

프로그램 하는 일 설치 방법
VS Code 코드 파일을 열고 편집하는 작업 공간 code.visualstudio.com에서 다운로드
Node.js 홈페이지를 내 컴퓨터에서 실행해주는 엔진 nodejs.org에서 LTS 버전 다운로드
Claude 확장 VS Code 안에서 Claude에게 일을 시키는 창 VS Code 왼쪽 확장(Extensions) 메뉴에서 "Claude Code" 검색 후 설치, 로그인

설치가 잘 됐는지 확인하려면 VS Code 상단 메뉴에서 터미널 → 새 터미널을 열고 아래를 입력해보세요. 숫자(버전)가 나오면 성공이에요.

node -v

마지막으로 바탕화면 같은 곳에 빈 폴더를 하나 만들고(예: my-homepage), VS Code에서 파일 → 폴더 열기로 그 폴더를 열어두세요. 앞으로 모든 작업은 이 폴더 안에서 해요.

2. 첫 프롬프트로 뼈대 만들기

아래 템플릿을 복사해서 [대괄호] 부분만 내 내용으로 바꾼 뒤 Claude 창에 붙여넣으세요. 모르는 칸은 "알아서 정해줘"라고 써도 괜찮아요.

나는 코딩을 전혀 모르는 사람이야. React(Vite)로 보드게임 소모임을 홍보하고, 보는 사람이 참가 신청 링크로 넘어갈 수 있는 간단한 홈페이지를 만들고 싶어.

[모임 정보]
- 모임 이름: [이름]
- 한 줄 소개: [예: 매주 토요일 오후, 초보도 환영하는 보드게임 모임]
- 이런 분께 추천: [예: 보드게임 처음 해보는 사람, 새 친구 사귀고 싶은 사람]

[들어갈 내용]
- 첫 화면: 모임 이름, 한 줄 소개, 대표 사진, 눈에 띄는 "참가 신청하기" 버튼
- 모임 소개: [분위기, 보통 인원, 참가비 여부 등 2~3문장]
- 일정·장소: [요일/시간, 장소]
- 주로 하는 게임: [게임 이름 3~5개] — 각각 카드 형태로 한 줄 설명
- 사진 갤러리: 모임 사진 몇 장
- 참가 방법: 버튼을 누르면 [오픈채팅/구글폼/카페 등] 링크로 이동
- 문의: [오픈채팅, 인스타그램 등 링크]

[사진과 링크]
- 사진은 내가 나중에 넣을 거라 일단 자리만 만들어두고, 어느 폴더에 어떤 이름으로 넣으면 되는지 알려줘.
- 버튼 링크들은 나중에 쉽게 바꿀 수 있게 한 파일에 모아두고, 바꾸는 방법을 알려줘.
- 외부 링크는 새 탭에서 열리게 해줘.
- 입력 양식(폼), 회원가입, 데이터 저장 기능은 필요 없어. 링크로 넘어가기만 하면 돼.

[분위기]
- 색감: [예: 따뜻하고 아기자기하게, 주사위·카드 느낌]
- 참고하고 싶은 느낌: [있으면 적기. 예를 들면 타홈페이지 사진이나 링크 첨부도 가능]

[부탁]
- 지금 이 폴더에 프로젝트를 새로 만들어줘. 필요한 설치도 알아서 해줘.
- 한 화면에 위에서 아래로 스크롤되는 구조로 해줘.
- 대부분 휴대폰으로 볼 테니 모바일에서 특히 잘 보이게 해줘.
- 다 만들면 내 컴퓨터에서 화면을 확인하는 방법을 쉬운 말로 알려줘.
- 무슨 파일을 왜 만들었는지 짧게 설명해줘.

[지켜야 할 규칙]
- 모든 작업은 지금 열려 있는 이 폴더 안에서만 해줘. 이 폴더 밖의 파일이나 폴더는 읽지도, 만들지도, 고치지도 마.
- 컴퓨터 전체에 설치하는 명령(npm install -g 등), 관리자 권한(sudo), 시스템 설정 변경은 하지 마.
- 파일이나 폴더를 지워야 할 때는 먼저 무엇을 왜 지우는지 말하고 내 허락을 받아줘.
- 이 규칙에 걸리는 작업이 꼭 필요하면 실행하지 말고 먼저 설명해줘.

Claude는 명령을 실행하거나 파일을 바꾸기 전에 "이거 해도 될까요?" 하고 물어봐요. 프롬프트에 규칙을 적어둬도 이 확인 단계가 진짜 안전장치이니, 아래 기준으로 판단하세요.

판단 이런 요청일 때
허용 이 폴더 안에서 파일 만들기·수정, npm install, npm run dev, npm run build
거절 이 폴더 밖 경로(바탕화면, 문서, C:\ 등)를 건드리는 작업
거절 파일·폴더 삭제(rm, del), 관리자 권한(sudo), 컴퓨터 전체 설치(-g), 시스템 설정 변경
거절 후 질문 무슨 뜻인지 모르겠는 요청 → "이게 뭐 하는 거야? 이 폴더 밖도 건드려?"
  • "항상 허용"이나 "다시 묻지 않기" 같은 선택지, 권한 확인을 건너뛰는 모드는 쓰지 마세요. 매번 묻는 게 귀찮아도 그게 보호막이에요.
  • Claude 창을 열 때는 꼭 VS Code에서 홈페이지 폴더를 연 상태여야 해요. Claude는 지금 열린 폴더를 작업 공간으로 삼아요.

3. 내 컴퓨터에서 화면 확인하기

뼈대가 만들어지면 터미널에 아래를 입력하세요. Claude에게 "실행해줘"라고 해도 돼요.

npm run dev

터미널에 http://localhost:5173 같은 주소가 뜨면 브라우저 주소창에 그대로 입력하세요. 내 홈페이지가 보이면 성공이에요.

  • 이 주소는 내 컴퓨터에서만 열려요. 다른 사람에게 보여주려면 5단계(인터넷에 올리기)를 해야 해요.
  • 켜둔 상태에서 코드를 고치면 브라우저 화면이 자동으로 바뀌어요.
  • 끄고 싶으면 터미널을 클릭하고 Ctrl + C를 누르면 돼요. 다음에 작업할 땐 다시 npm run dev만 하면 돼요.

4. 조금씩 고쳐가며 완성하기

가장 중요한 요령은 한 번에 하나씩 요청하고, 매번 브라우저에서 확인하는 거예요. 한꺼번에 많이 시키면 어디서 꼬였는지 찾기 어려워져요.

이렇게 말하기보다 이렇게 말하기
더 예쁘게 해줘 첫 화면 제목을 더 크게, 배경은 연한 회색으로 바꿔줘
이상해 휴대폰 크기로 보면 버튼이 화면 밖으로 삐져나가
기능 추가해줘 연락처 섹션 아래에 지도 대신 주소 텍스트를 넣어줘
다 갈아엎어줘 소개 섹션만 카드 3개가 가로로 놓이는 형태로 바꿔줘

화면을 캡처해서 Claude 창에 붙여넣고 "여기 이 부분"이라고 하면 훨씬 정확하게 알아들어요.

배우면서 하고 싶다면 요청 끝에 이 문장을 붙여보세요.

방금 바꾼 코드가 무슨 역할인지, 내가 직접 고치려면 어느 파일 어디를 보면 되는지 초보자 눈높이로 설명해줘.

익숙해지면 글자나 색 정도는 직접 파일을 열어 고쳐보세요. 그게 가장 빨리 느는 방법이에요.

4-1. 잘 될 때마다 저장하기 (되돌리기 대비)

Claude가 고치다 보면 가끔 멀쩡하던 화면이 망가지기도 해요. 그래서 마음에 드는 상태가 될 때마다 '저장 지점'을 만들어두는 게 좋아요. 이걸 Git이라는 도구가 해주는데, 어려운 건 Claude에게 맡기면 돼요.

처음 한 번만 이렇게 요청하세요.

이 프로젝트에 Git을 설정해주고 지금 상태를 첫 저장 지점으로 커밋해줘.

그 다음부터는 이 두 문장만 기억하면 돼요.

  • 잘 됐을 때: 지금 상태를 "소개 섹션 완성"이라는 이름으로 커밋해줘
  • 망가졌을 때: 마지막 커밋 상태로 되돌려줘

5. 인터넷에 올려서 주소 받기

완성되면 Cloudflare Pages에 무료로 올려서 누구나 접속할 수 있는 주소(이름.pages.dev)를 받을 수 있어요.

  1. Claude에게 요청하세요: 배포용으로 빌드해줘 → 프로젝트 안에 dist라는 폴더가 생겨요.
  2. dash.cloudflare.com에서 무료 회원가입 후 로그인해요.
  3. 메뉴에서 Workers & Pages → 만들기 → Pages → 파일 직접 업로드(Upload assets)를 골라요.
  4. 프로젝트 이름을 정하고(이게 주소가 돼요), dist 폴더를 통째로 끌어다 놓은 뒤 배포를 눌러요.
  5. 잠시 후 나오는 주소를 열어 확인하고 주변에 공유하면 끝이에요.

수정한 뒤 다시 올릴 때는 1번처럼 다시 빌드하고, 같은 프로젝트에서 새 배포로 dist를 올리면 돼요. Cloudflare 화면 메뉴 이름은 바뀔 수 있으니, 헷갈리면 화면을 캡처해서 Claude에게 물어보세요.

막혔을 때

대부분의 문제는 에러 메시지를 Claude에게 그대로 보여주면 해결돼요. 혼자 해석하려 하지 말고 이렇게 붙여넣으세요: 이런 에러가 났어. 쉬운 말로 원인이랑 해결해줘 + 에러 내용 복사.

증상 먼저 해볼 것
npm이나 node 명령을 못 찾는다고 나옴 Node.js 설치 후 VS Code를 완전히 껐다 켜기
브라우저에 아무것도 안 뜸 터미널에서 npm run dev가 켜져 있는지 확인
고쳤는데 화면이 그대로임 파일이 저장됐는지(Ctrl + S) 확인 후 새로고침
Claude가 고칠수록 더 꼬임 마지막 커밋으로 되돌리고, 요청을 더 작게 쪼개기
대화가 너무 길어져 Claude가 앞 내용을 헷갈림 새 대화를 열고 "이 프로젝트 구조를 먼저 파악해줘"로 시작

그래도 안 되면 지금 화면과 하려던 일을 캡처해서 주변 개발자에게 보여주세요. 그것도 충분히 좋은 공부예요.
